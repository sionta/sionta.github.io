Memeriksa Status Bootloader dan OEM Unlocking pada Android

Pelajari cara memeriksa status bootloader Android, memahami OEM unlocking, serta risiko dan persyaratan sebelum unlock bootloader.

Published
19 Jul 2020
Updated
9 Jul 2023
Category
Android Modding, Bootloader

Sebelum melakukan unlock bootloader, Anda perlu memahami dua hal: status bootloader saat ini dan apakah produsen mengizinkan unlock. Kedua hal ini tidak selalu sama.

Perangkat bisa saja memiliki opsi OEM unlocking yang aktif, tetapi bootloader tetap terkunci. Sebaliknya, beberapa produsen membatasi atau tidak menyediakan metode unlock resmi sama sekali.

Note

Artikel ini hanya menjelaskan pemeriksaan dan konsep. Perintah unlock bootloader akan dibahas pada artikel berikutnya, dengan prasyarat, risiko, dan verifikasi perangkat yang lebih lengkap.

Apa itu status bootloader?

Status bootloader menunjukkan seberapa bebas perangkat dapat menjalankan atau mem-flash software di luar kondisi pabrik.

AOSP menjelaskan bahwa device state menentukan seberapa bebas software dapat di-flash ke perangkat dan apakah verifikasi ditegakkan. Status dasarnya adalah LOCKED dan UNLOCKED.[2]

Note

Status bootloader bukan hanya informasi teknis. Status ini berpengaruh pada keamanan, Verified Boot, pembaruan, dan kompatibilitas aplikasi tertentu.

Apa itu OEM unlocking?

OEM unlocking adalah opsi di Developer Options yang mengizinkan bootloader untuk dibuka. Android menjelaskan bahwa OEM unlocking memungkinkan pengguna membuka bootloader, yang diperlukan untuk memasang custom Android OS atau melakukan modifikasi sistem tingkat rendah.[6]

Namun, OEM unlocking bukan proses unlock itu sendiri. Opsi ini hanya membuka kemungkinan unlock, sedangkan proses unlock tetap bergantung pada metode resmi produsen.

Warning

Android menyatakan bahwa unlock bootloader dapat memengaruhi garansi, berpotensi membuat perangkat tidak dapat digunakan, dan memiliki implikasi keamanan.[6]

Cara mengaktifkan Developer Options

Jika Developer Options belum aktif, lakukan langkah umum berikut:

  1. Buka Settings atau Pengaturan.
  2. Masuk ke About phone atau Tentang ponsel.
  3. Ketuk Build number atau Nomor bentukan tujuh kali.
  4. Kembali ke menu pengaturan.
  5. Buka System → Developer options.

Android menjelaskan bahwa Build Number perlu diketuk tujuh kali hingga muncul pesan bahwa pengguna berada dalam mode developer.[5]

Cara mengaktifkan OEM unlocking

Setelah Developer Options aktif:

  1. Buka Settings.
  2. Masuk ke System → Developer options.
  3. Cari opsi OEM unlocking.
  4. Aktifkan opsi tersebut.
  5. Masukkan kredensial layar kunci bila diminta.

Warning

Pada beberapa perangkat, opsi ini mungkin tidak tersedia, berwarna abu-abu, memerlukan koneksi internet, memerlukan akun produsen, atau dibatasi oleh kebijakan operator atau region. Jika opsi tidak tersedia, jangan memakai metode tidak resmi. Periksa dokumentasi resmi produsen untuk model dan region perangkat Anda.

Memeriksa variabel bootloader

Fastboot dapat membaca variabel konfigurasi atau versi dari bootloader melalui perintah getvar. Dokumentasi resmi Fastboot menjelaskan bahwa getvar digunakan untuk membaca variabel konfigurasi atau versi bootloader.[4]

Note

Tidak semua variabel tersedia pada semua perangkat. Nama variabel, format keluaran, dan dukungan perintah dapat berbeda antarprodusen.

Memahami hasil pemeriksaan

Artinya bootloader masih terkunci. Untuk banyak perangkat, ini adalah kondisi normal dari pabrik.

Jika Anda ingin modding tingkat lanjut, langkah berikutnya biasanya adalah:

  1. Memastikan OEM unlocking tersedia dan dapat diaktifkan.
  2. Membaca dokumentasi unlock resmi produsen.
  3. Memastikan backup sudah selesai.
  4. Memahami risiko penghapusan data dan perubahan Verified Boot.
  5. Baru melakukan unlock sesuai prosedur resmi.

Artinya bootloader sudah tidak terkunci. Perangkat mungkin sudah pernah dimodifikasi sebelumnya.

Periksa juga:

  • Apakah perangkat masih menjalankan stock ROM.
  • Apakah recovery masih stock atau sudah custom.
  • Apakah ada modul root yang terpasang.
  • Apakah slot aktif dan firmware sesuai.
  • Apakah ada aplikasi penting yang menolak karena status integritas.

Warning

Jangan langsung mem-flash image hanya karena bootloader sudah terbuka. Perangkat tetap harus dicocokkan berdasarkan model, codename, dan firmware.

Perbedaan OEM unlocking dan unlock bootloader

Note

Mengaktifkan OEM unlocking tidak otomatis membuka bootloader. Sebaliknya, beberapa perangkat mungkin sudah unlocked tanpa opsi OEM unlocking tampak aktif, tergantung implementasi vendor dan riwayat perangkat.

Mengapa status bootloader penting?

Menentukan kemampuan flashing — Perangkat LOCKED umumnya membatasi flashing software baru. AOSP menjelaskan bahwa device state menentukan seberapa bebas software dapat di-flash.[2]

Memengaruhi Verified Boot — Verified Boot dirancang untuk memastikan kode yang dijalankan berasal dari sumber tepercaya. Perubahan status bootloader dapat memengaruhi cara sistem menilai integritas boot.[3]

Memengaruhi aplikasi tertentu — Beberapa aplikasi memeriksa integritas perangkat sebelum mengizinkan akses. Google Play Integrity dapat memberikan verdict tentang kepercayaan terhadap perangkat dan aplikasi.

Menentukan jalur pemulihan — Status bootloader memengaruhi opsi flashing, recovery, dan metode pemulihan yang tersedia.

Persyaratan yang sering berbeda antarvendor

Jangan menganggap proses unlock sama untuk semua merek. Beberapa perbedaan umum antarvendor meliputi:

  • Ketersediaan opsi OEM unlocking.
  • Kebutuhan akun produsen.
  • Kebutuhan menunggu periode tertentu.
  • Kebutuhan aplikasi resmi atau token unlock.
  • Pembatasan berdasarkan region atau operator.
  • Perintah unlock yang berbeda.
  • Kebijakan garansi dan dukungan servis.

Note

AOSP mendokumentasikan mekanisme umum seperti fastboot flashing unlock, tetapi implementasi vendor dapat menambahkan syarat atau pembatasan tersendiri.

Miskonsepsi umum

“OEM unlocking aktif berarti bootloader sudah terbuka.” Tidak. OEM unlocking hanya mengizinkan proses unlock; status bootloader tetap harus diperiksa.

“Semua HP bisa di-unlock.” Tidak. Beberapa produsen membatasi, menonaktifkan, atau tidak menyediakan metode unlock resmi.

“Status unlocked berarti HP pasti sudah di-root.” Tidak. Bootloader unlocked hanya berarti perangkat dapat memuat atau mem-flash image alternatif; root adalah modifikasi terpisah.

“Fastboot getvar selalu menampilkan hasil yang sama di semua HP.” Tidak. Variabel dan keluaran dapat berbeda antarprodusen dan versi bootloader.

“Unlock bootloader aman karena bisa dikunci kembali.” Belum tentu. Proses lock kembali juga dapat menghapus data dan tidak selalu mengembalikan perangkat ke kondisi semula.

Checklist sebelum unlock bootloader

Sebelum melanjutkan ke artikel unlock bootloader, pastikan:

  • Developer Options sudah aktif.
  • Status OEM unlocking sudah diketahui.
  • Perangkat dapat terdeteksi oleh ADB.
  • Perangkat dapat masuk ke mode bootloader.
  • Perangkat terdeteksi oleh Fastboot.
  • Status bootloader sudah diperiksa.
  • Model, codename, dan region perangkat sudah terverifikasi.
  • Backup data sudah selesai dan tersimpan di luar perangkat.
  • Dokumentasi unlock resmi produsen sudah dibaca.
  • Anda memahami bahwa unlock dapat menghapus data dan memengaruhi keamanan.
