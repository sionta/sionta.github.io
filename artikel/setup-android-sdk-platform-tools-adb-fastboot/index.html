Menyiapkan PC dan Android SDK Platform-Tools untuk Modding

Pelajari cara mengunduh, memasang, dan memverifikasi Android SDK Platform-Tools agar ADB dan Fastboot siap digunakan untuk Android modding.

Published
5 Jul 2020
Updated
11 Jun 2023
Category
Android Modding, Bootloader

Sebelum melakukan unlock bootloader, memasang custom recovery, atau menginstal custom ROM, komputer Anda harus memiliki Android SDK Platform-Tools. Paket ini menyediakan dua alat utama: ADB dan Fastboot.

Artikel ini menjelaskan persiapan PC, pengunduhan resmi, verifikasi instalasi, serta praktik aman sebelum menggunakan perintah yang lebih berisiko.

Catatan: Artikel ini menggunakan pendekatan lintas platform. Contoh perintah ditulis untuk Windows, tetapi ADB dan Fastboot juga tersedia untuk macOS dan Linux melalui paket resmi Android SDK Platform-Tools.

Apa itu Android SDK Platform-Tools?

Android SDK Platform-Tools adalah komponen Android SDK yang berisi alat untuk berinteraksi dengan perangkat Android. Paket ini mencakup adb dan fastboot. 1

Dalam konteks modding:

  • ADB digunakan saat Android normal berjalan, misalnya untuk debugging, transfer file, atau reboot ke mode tertentu.
  • Fastboot digunakan saat perangkat berada di mode bootloader, misalnya untuk memeriksa perangkat atau melakukan flashing bila bootloader mengizinkan.

Android Developers menjelaskan bahwa ADB adalah alat baris perintah serbaguna untuk berkomunikasi dengan perangkat Android, dan ADB termasuk dalam paket Android SDK Platform Tools. 1

Apa yang perlu disiapkan?

Sebelum mulai, siapkan:

  • Komputer Windows, macOS, atau Linux yang stabil.
  • Kabel USB yang mendukung transfer data, bukan kabel charge-only.
  • Perangkat Android dengan baterai cukup.
  • Akses internet untuk mengunduh paket resmi.
  • Folder khusus untuk menyimpan Platform-Tools, ROM, recovery, dan firmware.
  • Backup data yang sudah selesai dan terverifikasi.

Jangan menyimpan file modding secara acak di Desktop atau folder unduhan. Buat struktur folder yang rapi agar mudah ditemukan saat dibutuhkan.

Mengunduh Android SDK Platform-Tools

Selalu unduh dari halaman resmi Android Developers. Jangan menggunakan paket dari sumber tidak dikenal, terutama bila paket tersebut diklaim sebagai “ADB universal”, “Fastboot all device”, atau menyertakan skrip tambahan.

Android Developers menyediakan paket standalone Android SDK Platform-Tools dan menyatakan bahwa ADB termasuk dalam paket tersebut. 1 Dokumentasi command-line tools juga menyebut lokasi standar SDK Platform Tools pada android_sdk/platform-tools/. 2

Langkah unduh resmi

  1. Buka halaman resmi Android SDK Platform-Tools release notes.
  2. Pilih paket sesuai sistem operasi komputer Anda.
  3. Unduh file ZIP resmi.
  4. Ekstrak ke folder khusus, misalnya C:\AndroidModding\platform-tools pada Windows.
  5. Pastikan folder berisi adb.exe dan fastboot.exe pada Windows.

Pada macOS atau Linux, nama file yang dapat dijalankan umumnya adalah adb dan fastboot tanpa akhiran .exe.

Masalah umum saat setup

adb tidak dikenali

Kemungkinan penyebab:

  • Platform-Tools belum diekstrak.
  • Folder Platform-Tools belum ditambahkan ke PATH.
  • Terminal belum direstart setelah mengubah PATH.
  • Perintah diketik salah, misalnya adb.exe pada macOS atau Linux.

Solusi:

  • Masuk langsung ke folder Platform-Tools.
  • Jalankan .\adb version pada Windows atau ./adb version pada macOS/Linux.
  • Periksa kembali konfigurasi PATH.

fastboot tidak dikenali

Kemungkinan penyebab:

  • File fastboot tidak ada karena paket tidak lengkap.
  • Folder Platform-Tools belum ada di PATH.
  • Terminal belum direstart.

Solusi:

  • Pastikan paket diunduh dari sumber resmi.
  • Ekstrak ulang paket.
  • Periksa isi folder Platform-Tools.
  • Jalankan perintah dari dalam folder Platform-Tools terlebih dahulu.

Perangkat tidak terdeteksi ADB

Kemungkinan penyebab:

  • USB debugging belum aktif.
  • Dialog otorisasi RSA belum disetujui.
  • Kabel hanya mendukung pengisian daya.
  • Driver belum terpasang dengan benar.
  • Port USB bermasalah.

Solusi:

  • Aktifkan USB debugging.
  • Buka layar perangkat dan setujui dialog RSA.
  • Ganti kabel atau port USB.
  • Gunakan driver resmi atau yang direkomendasikan produsen.

Perangkat tidak terdeteksi Fastboot

Kemungkinan penyebab:

  • Perangkat belum berada di mode bootloader/Fastboot.
  • Driver Fastboot belum terpasang.
  • Kabel atau port USB bermasalah.
  • Perangkat memakai mode Fastboot berbeda, seperti FastbootD.

Solusi:

  • Pastikan perangkat benar-benar berada di mode Fastboot.
  • Coba adb reboot bootloader dari Android normal.
  • Ganti kabel atau port USB.
  • Periksa driver sesuai produsen dan sistem operasi.

Praktik aman sebelum modding

  • Gunakan hanya Platform-Tools dari sumber resmi.
  • Jangan menjalankan skrip .bat, .sh, atau .ps1 dari sumber tidak dikenal.
  • Baca setiap perintah sebelum menyalinnya ke terminal.
  • Jangan menjalankan perintah flashing hanya karena ada di komentar video atau forum.
  • Simpan ROM, recovery, firmware, dan backup di folder terpisah.
  • Pastikan baterai perangkat cukup.
  • Jangan mencabut kabel saat proses transfer atau flashing berlangsung.
  • Catat versi Platform-Tools yang digunakan.

Kapan Platform-Tools diperlukan?

Tabel ini bersifat umum. Perilaku sebenarnya bergantung pada perangkat, recovery, dan dokumentasi ROM.

Miskonsepsi umum

“Harus menginstal Android Studio untuk memakai ADB.”

Tidak selalu. Android Developers menyediakan paket standalone Android SDK Platform-Tools yang mencakup ADB. 1

“ADB dan Fastboot selalu terdeteksi bersamaan.”

Tidak. ADB bekerja saat Android normal berjalan, sedangkan Fastboot bekerja pada mode bootloader.

“Semua driver ADB sama untuk semua HP.”

Tidak selalu. Driver dapat bergantung pada produsen, chipset, dan mode perangkat.

“Kalau adb devices kosong, berarti Platform-Tools rusak.”

Belum tentu. Periksa USB debugging, otorisasi RSA, kabel, port USB, dan driver.

“Menambahkan PATH berarti perangkat otomatis terdeteksi.”

Tidak. PATH hanya memudahkan menjalankan perintah. Deteksi perangkat tetap bergantung pada mode perangkat, kabel, driver, dan otorisasi.

Checklist sebelum lanjut

Sebelum melanjutkan ke unlock bootloader, pastikan:

  • Android SDK Platform-Tools diunduh dari sumber resmi.
  • Folder Platform-Tools berisi adb dan fastboot.
  • adb version berhasil dijalankan.
  • fastboot --version berhasil dijalankan.
  • USB debugging dapat diaktifkan pada perangkat.
  • Perangkat terdeteksi oleh adb devices setelah otorisasi.
  • Perangkat dapat masuk ke mode bootloader.
  • Perangkat terdeteksi oleh fastboot devices, bila mode dan driver sudah sesuai.
  • Backup data sudah selesai dan tersimpan di luar perangkat.
