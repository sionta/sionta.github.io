Hugo: struktur layout yang tidak melelahkan

Tema yang baik terasa kecil, satu baseof, beberapa partial, dan tiap file punya satu tugas.

Published
28 Sep 2026
Updated
20 Oct 2026
Category
Hugo

Setiap tema Hugo dimulai dari satu file, baseof.html, yang memegang kerangka dokumen. Setiap halaman hanya mengisi block "main". Header dan footer dibaca dari menu di konfigurasi, jadi menambah halaman cukup dengan satu file Markdown.

Ringkasan

Satu baseof.html, partial kecil untuk bagian yang berulang, dan layout per section untuk halaman yang memang berbeda.

Tiga file yang perlu dibaca

Warning

Nama file menentukan layout yang dipakai: page.html untuk halaman tunggal, section.html untuk daftar. Salah nama membuat Hugo diam-diam memakai layout cadangan.

Bagaimana jika tiap section butuh layout berbeda?

Buat folder layouts/<section>/ berisi page.html dan section.html. Hugo memilihnya sebelum layout umum.

Bolehkah baseof punya lebih dari satu block?

Boleh. Tambahkan block lain, misalnya head atau scripts, lalu isi dari layout yang membutuhkannya.

Partial, shortcode, atau render hook?

Kalau sebuah partial butuh lebih dari satu penjelasan, ia sebenarnya dua partial.

Penutup

Mulai dari kerangka paling kecil, lalu pecah hanya ketika ada pengulangan nyata.

Tip

Pecah ke partial hanya setelah ada pengulangan nyata.
