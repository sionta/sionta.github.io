First Boot, Verifikasi Custom ROM, dan Pemecahan Masalah Awal

Pelajari cara memverifikasi custom ROM setelah first boot, menguji fungsi dasar Android, membaca logcat, dan menangani masalah awal secara aman.

Published
13 Mar 2022
Updated
12 Jan 2025
Category
Android Modding, Custom ROM

Setelah custom ROM dan add-on yang diperlukan selesai dipasang, perangkat akan menjalani first boot. Ini adalah proses pertama perangkat menyala dengan ROM baru, dan dapat memakan waktu lebih lama daripada boot normal.

Jangan langsung memasang root, modul, atau tweak sistem sebelum Anda memastikan ROM berjalan stabil dan fungsi dasar perangkat berfungsi.

Prinsip utama: Verifikasi dulu, modifikasi kemudian. Perangkat yang belum stabil sebaiknya tidak diberi tambahan modul atau modifikasi sistem.

Apa itu first boot?

First boot adalah proses pertama perangkat menyala setelah ROM baru dipasang. Selama proses ini, Android dapat:

  • Menyiapkan partisi data.
  • Membuat struktur penyimpanan baru.
  • Mengoptimalkan aplikasi.
  • Menyiapkan layanan sistem.
  • Menjalankan setup wizard.
  • Menyiapkan komponen vendor dan firmware.

Pada beberapa perangkat, first boot dapat memakan waktu lebih lama dari biasanya. Dokumentasi LineageOS untuk POCO F1 menyatakan bahwa first boot umumnya tidak lebih dari 15 menit, tergantung perangkat. 1

Namun, angka tersebut bukan patokan universal. Perangkat lambat, penyimpanan besar, atau ROM tertentu dapat membutuhkan waktu berbeda.

Sebelum reboot pertama

Sebelum reboot ke sistem, pastikan:

  • ROM sudah selesai dipasang.
  • GApps atau add-on wajib sudah dipasang.
  • Firmware dasar sesuai.
  • Recovery kompatibel.
  • Tidak ada langkah instalasi yang terlewat.
  • Backup data tersimpan di luar perangkat.
  • Anda sudah membaca seluruh instruksi ROM.

Dokumentasi LineageOS untuk POCO F1 mengarahkan pengguna menyelesaikan instruksi instalasi sebelum reboot ke sistem. 1 Urutan dan langkah dapat berbeda pada perangkat lain, jadi ikuti panduan ROM perangkat Anda.

Cara reboot pertama yang aman

Setelah semua langkah selesai:

  1. Kembali ke menu utama recovery.
  2. Pilih Reboot system now.
  3. Tunggu proses first boot selesai.
  4. Jangan mencabut kabel atau memaksa shutdown.
  5. Jangan memasang aplikasi atau modul sebelum sistem stabil.

LineageOS menunjukkan pola ini pada halaman instalasi: setelah semua paket berhasil dipasang, pengguna dapat memilih Reboot system now untuk boot pertama ke OS. 1

Berapa lama first boot normal?

Tidak ada angka universal. First boot dapat berlangsung beberapa menit hingga belasan menit, tergantung:

  • Kecepatan penyimpanan.
  • Ukuran penyimpanan internal.
  • Jumlah aplikasi bawaan.
  • Versi Android.
  • Optimasi ROM.
  • Kondisi firmware.
  • Kecepatan prosesor.

Jika perangkat masih stuck setelah waktu yang wajar menurut dokumentasi ROM, jangan langsung mem-flash ulang. Lakukan diagnosis terlebih dahulu.

Verifikasi fungsi dasar

Setelah perangkat masuk ke layar utama, uji fungsi dasar secara bertahap.

Jangan menganggap ROM gagal hanya karena satu fitur bermasalah. Catat gejalanya, lalu periksa halaman ROM atau laporan bug.

Verifikasi versi ROM

Pastikan ROM yang berjalan benar-benar sesuai dengan yang Anda instal.

Periksa melalui:

  • Settings → About phone
  • Build number
  • Android version
  • LineageOS version atau versi ROM, bila tersedia
  • Kernel version
  • Baseband version

Gunakan logcat untuk diagnosis

Logcat adalah alat untuk melihat log sistem Android. Logcat dapat membantu mengenali error, crash, atau masalah layanan tertentu.

Android Developers menjelaskan bahwa Logcat adalah alat baris perintah yang menampilkan log pesan sistem, termasuk pesan yang ditulis aplikasi.

Masalah umum setelah first boot

Kapan first boot dianggap gagal?

Pertimbangkan first boot gagal bila:

  • Perangkat stuck di logo sangat lama sesuai batas yang disebut dokumentasi ROM.
  • Perangkat restart berulang kali.
  • Setup wizard crash berulang.
  • Recovery tidak dapat diakses.
  • Perangkat tidak terdeteksi ADB maupun Fastboot.
  • Sistem masuk, tetapi hampir semua fungsi utama tidak berfungsi.

Jangan langsung melakukan factory reset atau flashing ulang. Kumpulkan informasi terlebih dahulu.

Kapan perlu clean flash ulang?

Clean flash ulang dapat dipertimbangkan bila:

  • ROM tidak dapat boot setelah diagnosis.
  • GApps atau add-on terpasang salah.
  • Firmware dasar ternyata tidak sesuai.
  • Terjadi konflik data dari instalasi sebelumnya.
  • Maintainer ROM menyarankan clean flash.
  • Dirty flash sebelumnya menyebabkan masalah.

Namun, clean flash akan berisiko kehilangan data. Pastikan backup sudah tersedia sebelum melanjutkan.

Kapan tidak perlu clean flash?

Tidak semua masalah memerlukan clean flash. Beberapa masalah dapat diselesaikan dengan:

  • Menunggu proses optimisasi selesai.
  • Memperbarui ROM ke build perbaikan.
  • Menghapus atau menonaktifkan aplikasi tertentu.
  • Memeriksa pengaturan jaringan atau akun.
  • Melaporkan bug ke maintainer.
  • Menunggu perbaikan pada build berikutnya.

Praktik aman setelah ROM stabil

Setelah ROM berjalan normal:

  • Jangan langsung memasang banyak modul.
  • Jangan langsung melakukan root bila belum diperlukan.
  • Aktifkan backup berkala.
  • Catat versi ROM dan firmware.
  • Periksa pembaruan dari kanal resmi.
  • Laporkan bug ke kanal resmi ROM, bukan menyebarkan solusi tidak terverifikasi.

Miskonsepsi umum

“First boot lama berarti ROM gagal.”

Belum tentu. First boot dapat memakan waktu lebih lama karena optimisasi dan penyiapan sistem. 1

“Kalau ada bug, langsung ganti ROM.”

Belum tentu. Periksa dulu apakah bug sudah diketahui, apakah ada perbaikan, dan apakah masalahnya berasal dari firmware atau GApps.

“Logcat hanya untuk developer.”

Logcat dapat membantu diagnosis masalah, tetapi log perlu diperiksa untuk informasi sensitif sebelum dibagikan.

“Semua masalah setelah instalasi berarti ROM buruk.”

Belum tentu. Penyebabnya bisa firmware, GApps, recovery, data lama, atau langkah instalasi yang belum lengkap.

“Root harus langsung dipasang setelah ROM stabil.”

Tidak. Root adalah modifikasi tambahan dengan risiko tersendiri. Pasang hanya bila benar-benar diperlukan.

Checklist setelah first boot

  • Perangkat masuk ke layar utama.
  • Tidak ada bootloop.
  • Setup wizard selesai.
  • Wi-Fi berfungsi.
  • Jaringan seluler berfungsi, bila digunakan.
  • Kamera dan sensor berfungsi.
  • Audio dan mikrofon berfungsi.
  • Sidik jari atau face unlock berfungsi, bila didukung.
  • Versi ROM dan firmware tercatat.
  • Backup baru dibuat setelah sistem stabil.
  • Belum ada modul atau tweak yang dipasang sebelum verifikasi selesai.
