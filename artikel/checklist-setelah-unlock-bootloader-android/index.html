Checklist Setelah Unlock Bootloader Android

Pelajari checklist aman setelah unlock bootloader Android: verifikasi boot, ADB, Fastboot, slot A/B, status unlocked, firmware, dan kesiapan instalasi recovery.

Published
6 Sep 2020
Updated
8 Oct 2023
Category
Android Modding, Bootloader

Setelah unlock bootloader berhasil, jangan langsung mem-flash recovery, custom ROM, atau root. Lakukan pemeriksaan terlebih dahulu untuk memastikan perangkat masih boot normal, terdeteksi oleh komputer, dan siap untuk tahap berikutnya.

Artikel ini memberikan checklist verifikasi pasca-unlock. Tujuannya adalah mengurangi risiko salah diagnosis dan mencegah pembaca melanjutkan ke proses berisiko ketika perangkat sebenarnya belum siap.

Prinsip utama: Unlock bootloader bukan akhir dari persiapan. Ini adalah awal dari tahap di mana kesalahan memilih image atau partisi dapat menyebabkan perangkat gagal boot.

Apa yang perlu diverifikasi?

Setelah unlock, periksa hal-hal berikut:

  1. Perangkat dapat boot normal.
  2. Perangkat dapat terdeteksi oleh ADB.
  3. Perangkat dapat masuk ke mode bootloader.
  4. Perangkat terdeteksi oleh Fastboot.
  5. Status bootloader benar-benar unlocked.
  6. Slot aktif teridentifikasi pada perangkat A/B.
  7. Firmware dan build number tercatat.
  8. Recovery masih berfungsi.
  9. File recovery, ROM, dan firmware sudah disiapkan sesuai codename.
  10. Backup tetap tersimpan di luar perangkat.

1. Pastikan perangkat boot normal

Setelah proses unlock, banyak perangkat akan melakukan reset dan memulai setup awal. Tunggu hingga perangkat benar-benar masuk ke layar utama Android.

Periksa hal berikut:

  • Perangkat tidak stuck di logo.
  • Perangkat tidak bootloop.
  • Layar sentuh berfungsi.
  • Wi-Fi dan Bluetooth dapat diaktifkan.
  • SIM card terbaca, bila digunakan.
  • Kamera, sensor, dan speaker berfungsi normal.
  • Perangkat tidak menampilkan error yang tidak dikenal.

Jika perangkat gagal boot atau bootloop, jangan langsung mem-flash image apa pun. Gunakan alur diagnosis dari langkah paling aman terlebih dahulu.

2. Verifikasi koneksi ADB

Setelah setup awal selesai, aktifkan kembali USB debugging bila perangkat telah di-reset.

Langkah umumnya:

  1. Buka Settings.
  2. Masuk ke About phone.
  3. Ketuk Build number tujuh kali untuk mengaktifkan Developer Options.
  4. Buka System → Developer options.
  5. Aktifkan USB debugging.
  6. Hubungkan perangkat ke komputer.
  7. Setujui dialog otorisasi RSA di layar perangkat.

6. Catat firmware dan build number

Setelah perangkat boot normal, catat kembali:

  • Model number.
  • Codename.
  • Versi Android.
  • Build number.
  • Build fingerprint.
  • Versi baseband atau modem, bila tersedia.
  • Versi kernel, bila tersedia.

Informasi ini penting karena recovery, ROM, dan firmware harus sesuai dengan kondisi perangkat saat ini.

7. Periksa recovery bawaan

Setelah unlock, recovery bawaan biasanya masih ada kecuali Anda sudah menggantinya. Masuk ke recovery untuk memastikan fungsi dasarnya berjalan.

Cara masuk recovery berbeda antarperangkat. Pada beberapa perangkat, Anda dapat memilih opsi recovery dari mode bootloader; pada perangkat lain, gunakan kombinasi tombol fisik atau perintah khusus vendor.

Periksa apakah recovery dapat:

  • Masuk tanpa error.
  • Menampilkan menu dasar.
  • Melakukan reboot.
  • Menampilkan opsi factory reset atau apply update, bila tersedia.

Jangan melakukan factory reset atau flashing hanya untuk “menguji” recovery.

8. Siapkan file untuk tahap berikutnya

Sebelum melanjutkan ke recovery atau custom ROM, pastikan file berikut sudah disiapkan dan tersimpan di luar perangkat:

  • Recovery resmi yang sesuai codename.
  • Custom ROM resmi yang sesuai codename.
  • Firmware dasar yang direkomendasikan ROM, bila diperlukan.
  • Firmware resmi untuk pemulihan, bila tersedia.
  • Magisk atau alat root resmi, bila rencananya akan root.
  • Backup data yang terverifikasi.

Jangan menyimpan satu-satunya salinan file penting di penyimpanan internal perangkat.

9. Pahami peringatan Verified Boot

Setelah unlock, perangkat dapat menampilkan peringatan saat boot. Ini adalah perilaku keamanan yang wajar pada banyak perangkat.

Dokumentasi Android Verified Boot 2.0 menjelaskan bahwa pada status UNLOCKED, verifikasi error tidak lagi bersifat fatal, dan pengguna harus selalu diberi peringatan bahwa verifikasi tidak berlangsung.

Artinya, peringatan unlock bukan berarti perangkat rusak. Namun, peringatan tersebut menandakan bahwa perangkat tidak lagi berada dalam kondisi keamanan pabrik yang sepenuhnya terkunci.

10. Jangan langsung flashing

Kesalahan umum setelah unlock adalah langsung mem-flash file apa pun yang ditemukan di internet. Jangan lakukan itu.

Sebelum flashing, pastikan:

  • File benar-benar untuk codename perangkat Anda.
  • File berasal dari sumber resmi.
  • Versi recovery dan ROM kompatibel.
  • Firmware dasar sesuai.
  • Metode instalasi sesuai dokumentasi perangkat.
  • Backup sudah selesai.
  • Perangkat terdeteksi ADB atau Fastboot sesuai kebutuhan.

Checklist akhir pasca-unlock

Gunakan checklist berikut sebelum lanjut:

  • Perangkat dapat boot normal.
  • Perangkat tidak bootloop.
  • USB debugging aktif.
  • Perangkat terdeteksi oleh adb devices.
  • Perangkat dapat masuk ke mode bootloader.
  • Perangkat terdeteksi oleh fastboot devices.
  • Status bootloader terverifikasi unlocked.
  • Slot aktif tercatat, bila perangkat A/B.
  • Firmware dan build number tercatat.
  • Recovery bawaan masih dapat diakses.
  • Recovery, ROM, dan firmware sudah disiapkan sesuai codename.
  • Backup tersimpan di luar perangkat.
  • Anda memahami peringatan Verified Boot.
  • Anda belum mem-flash file apa pun tanpa verifikasi.

Miskonsepsi umum

“Setelah unlock, langsung flash recovery.”

Belum tentu. Beberapa perangkat lebih aman atau memang direkomendasikan untuk boot recovery sementara terlebih dahulu. Ikuti dokumentasi perangkat.

“Peringatan unlock berarti HP rusak.”

Tidak. Peringatan tersebut adalah bagian dari perilaku Verified Boot pada perangkat unlocked.

“Semua perangkat A/B punya variabel current-slot.”

Sebagian besar perangkat A/B modern menyediakannya, tetapi dukungan dan format keluaran dapat berbeda antarvendor.

“Setelah unlock, semua ROM bisa dipasang.”

Tidak. ROM tetap harus sesuai codename, varian, firmware dasar, dan metode instalasi perangkat.

“Kalau ADB terdeteksi, Fastboot pasti terdeteksi.”

Tidak. Keduanya bekerja pada mode perangkat dan driver yang berbeda.
