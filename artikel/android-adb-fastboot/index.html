Perintah adb dan fastboot yang paling sering dipakai

Cheatsheet perintah adb dan fastboot yang benar-benar dipakai saat flashing dan perbaikan.

Diterbitkan
17 Agustus 2026
Penulis

Semua artikel

Hampir semua pekerjaan di seri ini dijalankan lewat dua program. Keduanya sudah ada di dalam paket platform-tools dari Google, jadi kamu tidak perlu mencari binary random di internet.

adb bicara dengan Android yang sedang hidup. fastboot bicara dengan bootloader, yaitu sistem yang berjalan sebelum Android ada. Bedanya penting, dan salah memilih mode akan menghasilkan error yang membingungkan.

Dua mode, dua protocol

Tidak ada wizard untuk berpindah mode. Kamu yang memindahkan ponsel ke mode yang benar.

Masuk fastboot tanpa adb:

  • Volume turun plus tombol daya.
  • Volume naik plus tombol daya pada beberapa model lama.
  • Kombinasi tombol lain, tergantung merk.

Masuk recovery bawaan tanpa adb:

  • Tombol daya plus volume naik.
  • Atau lewat bootloader dengan fastboot boot recovery.img bila file-nya kamu punya.

Keluar dari fastboot atau recovery kalau bootloader kamu macet: tombol power tahan sekitar sepuluh detik. Ponselnya akan restart sendiri ke sistem.

Persiapan di Windows

Unduh platform-tools dari halaman resmi, lalu tambahkan foldernya ke PATH. Setelah itu adb dan fastboot bisa dipanggil dari mana saja.

Buka Settings > About phone, tekan Build number tujuh kali. Menu Developer options baru muncul di situ.

Yang perlu dinyalakan:

  • USB debugging, untuk adb.
  • OEM unlocking, untuk fastboot unlock. Opsi ini hanya muncul kalau bootloader memang bisa dibuka di perangkatmu.

Driver USB adalah sumber masalah nomor satu di Windows. Google USB Driver sering tidak mengenali perangkat MediaTek. Untuk Xiaomi, Samsung, dan sebagian besar brand besar, pakai driver yang disediakan OEM. Driver MediaTek perlu dua berkas: satu untuk MTP dan satu untuk preloader.

adb: perintah harian

PerintahYang terjadi
adb devicesDaftar perangkat yang terhubung
adb shellMembuka shell di ponsel
adb install -r file.apkPasang aplikasi, pertahankan data lama
adb uninstall id.aplikasiCopot aplikasi
adb pull /sdcard/DCIM .Menarik folder ke komputer
adb push file.zip /sdcard/Mendorong file ke ponsel
adb logcatAlur log langsung
adb reboot bootloaderPindah ke fastboot
adb sideload file.zipFlash ZIP saat mode recovery aktif
adb wait-for-deviceTunggu perangkat siap, berguna untuk loop

Status unauthorized di adb devices bukan error teknis. Artinya kamu belum mengetuk Allow di dialog sidik jari RSA di layar ponsel. Dialog itu hanya muncul sekali per komputer per perangkat. Kalau tidak muncul, putuskan kabel dan ulangi.

Untuk baca log saat boot yang macet, adb logcat tidak akan menolong karena adb butuh Android yang sudah hidup. Di fastboot kamu tidak punya log sama sekali. Di fastboot tidak ada log sistem. Yang kamu baca hanya output fastboot itu sendiri.

fastboot: perintah yang kamu butuh

PerintahYang terjadi
fastboot devicesCek apakah ponsel terdeteksi
fastboot getvar allSemua variabel bootloader
fastboot flashing get_unlock_abilityCek apakah perangkat bisa dibuka
fastboot flashing unlockBuka bootloader
fastboot flashing lockKunci ulang, biasanya dengan wipe
fastboot flash boot boot.imgTulis satu partisi
fastboot flash super super.imgTulis wadah dynamic partitions
fastboot flash vbmeta vbmeta.imgTulis header verifikasi
fastboot boot file.imgBoot image tanpa mem-flash
fastboot --wipeHapus userdata dan cache
fastboot set_active aPilih slot A pada perangkat A/B

Perintah fastboot boot adalah tool paling berguna di daftar ini. Ia memuat image secara sementara, tanpa menulis apa pun ke flash. Kalau image-nya salah, kamu hanya perlu unplug dan restart. Tidak ada yang rusak.

Sebaliknya, fastboot flashing unlock menghapus userdata karena isinya tidak lagi ditandatangani OEM. Ini bukan pilihan gaya, tapi syarat dari AOSP.

Menarik file tanpa lewat MTP

MTP lambat dan sering putus di tengah transfer. Untuk file boot, log, dan screenshot, adb lebih cepat dan lebih bisa diprediksi.

Perintah kedua mengambil tangkapan layar tanpa menulis file dulu di ponsel. Di Windows PowerShell, > bisa mengubah encoding gambar. Pakai adb exec-out screencap -p > layar.png dari Command Prompt, atau tulis lewat cmd /c kalau kamu tetap di PowerShell.

Dua kesalahan yang paling sering

Menjalankan fastboot saat ponsel masih di Android. Output-nya fastboot: error: no devices found padahal kabel terpasang. Perintahnya bukan fastboot flash boot boot.img, tapi adb reboot bootloader dulu, baru jalankan fastboot.

Lupa bahwa fastboot menulis langsung ke flash. Tidak ada konfirmasi, tidak ada tombol batal, tidak ada recycle bin. Sebelum menjalankan fastboot flash, pastikan nama image-nya benar dan partisi tujuannya benar. Bootloader yang salah menulis super karena satu huruf akan menghapus seluruh sistem operasi, Kesalahan ini terjadi pada sesi yang terburu-buru, dan tidak ada tombol batal.
