Memilih Image yang Tepat untuk Root: Boot, Init Boot, atau Recovery

Pelajari cara memilih image yang tepat untuk root Magisk berdasarkan boot, init_boot, atau recovery serta risiko salah pilih partisi.

Published
26 Oct 2026
Updated
26 Oct 2026
Category
Android Modding, Root

Kesalahan paling umum saat root adalah mem-patch image yang salah. Tidak semua perangkat memakai boot.img sebagai target root. Pada perangkat Android 13 ke atas, target bisa init_boot.img. Pada perangkat tertentu, recovery dapat menjadi target.

Artikel ini menjelaskan cara menentukan image yang tepat berdasarkan perangkat, firmware, dan dokumentasi resmi.

Peringatan: Jangan menebak target patch. Salah image atau salah partisi dapat menyebabkan perangkat gagal boot.

Mengapa target root berbeda?

Target root berbeda karena struktur partisi Android berbeda.

Faktor yang memengaruhi:

  • Generasi Android.
  • Arsitektur SoC.
  • Keputusan produsen.
  • Struktur partisi.
  • Penggunaan GKI.
  • Penggunaan recovery-as-boot.

Image boot.img

boot.img umumnya memuat kernel dan, pada banyak generasi perangkat, ramdisk.

Pada perangkat yang masih memakai ramdisk di boot, target root biasanya adalah boot.img.

Image init_boot.img

init_boot.img menyimpan generic ramdisk pada perangkat yang diluncurkan dengan Android 13. AOSP menjelaskan bahwa generic ramdisk dipindahkan dari boot ke init_boot pada perangkat tersebut. [190]

Artinya, pada perangkat tertentu, target root adalah init_boot.img, bukan boot.img.

Image recovery.img

Pada perangkat tertentu, recovery dapat menjadi target patch Magisk. Dokumentasi Magisk menyebut opsi patch boot/init_boot/recovery. [38]

Namun, ini bukan pola universal. Jangan mematch recovery hanya karena tutorial lain melakukannya.

Perbandingan image

Risiko salah pilih image

  • Bootloop.
  • Perangkat gagal boot.
  • Root gagal.
  • Recovery rusak.
  • OTA gagal.
  • Firmware tidak kompatibel.

Miskonsepsi umum

“Semua perangkat mematch boot.img.”

Tidak. Perangkat Android 13+ dapat mematch init_boot.img. [190]

“Recovery selalu jadi target root.”

Tidak. Recovery hanya relevan pada perangkat tertentu.

“Versi Android sama, berarti target sama.”

Tidak. Struktur partisi dan firmware dapat berbeda.

“Magisk otomatis memilih image yang benar.”

Tidak. Pengguna tetap harus memilih file yang tepat.

Checklist sebelum patch

  • Codename terverifikasi.
  • Firmware sesuai.
  • Struktur partisi diketahui.
  • Dokumentasi Magisk dibaca.
  • Image yang tepat sudah dipilih.
  • Backup selesai.
  • Jalur pemulihan tersedia.
