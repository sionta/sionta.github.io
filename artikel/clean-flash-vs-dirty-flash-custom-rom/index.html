Clean Flash vs Dirty Flash pada Custom ROM Android

Pelajari perbedaan clean flash dan dirty flash pada custom ROM Android, kapan format data diperlukan, serta risiko update tanpa wipe data.

Published
26 Oct 2026
Updated
26 Oct 2026
Category
Android Modding, Custom ROM

Clean flash adalah instalasi custom ROM dengan membersihkan data atau partisi tertentu terlebih dahulu. Dirty flash adalah instalasi ROM atau pembaruan di atas instalasi sebelumnya tanpa menghapus data pengguna.

Metode update bergantung pada dukungan ROM, versi, dan kondisi perangkat. Dirty flash hanya dilakukan bila maintainer ROM menyatakannya didukung. Jika dokumentasi tidak menjelaskan operasi yang diperlukan, berhenti dan periksa panduan perangkat; jangan menganggap clean flash atau format data otomatis menjadi pilihan aman.

Prinsip utama: Jangan melakukan dirty flash hanya karena ingin cepat. Ikuti dokumentasi ROM dan pastikan operasi wipe yang diminta jelas sebelum melanjutkan.

Apa itu clean flash?

Clean flash adalah proses instalasi ROM dengan membersihkan data atau partisi tertentu sebelum ROM dipasang.

Clean flash adalah istilah umum, bukan nama satu operasi wipe yang seragam. Ikuti langkah persis yang ditetapkan dokumentasi ROM untuk perangkat Anda.

Jika instruksi meminta factory reset, jangan menganggapnya sama dengan format data. Format data dapat menghapus enkripsi dan file di penyimpanan internal. Backup data penting ke luar perangkat dan verifikasi salinannya sebelum menjalankan salah satu operasi tersebut.

Apa itu dirty flash?

Dirty flash adalah proses memasang ROM atau pembaruan di atas instalasi sebelumnya tanpa menghapus data pengguna.

Dirty flash biasanya dilakukan untuk:

  • Memperbarui ROM dalam versi yang sama.
  • Menerapkan perbaikan bug kecil.
  • Mengganti build nightly atau weekly dalam jalur yang sama.
  • Menguji perbaikan tertentu tanpa setup ulang.

Namun, dirty flash hanya aman bila maintainer ROM secara eksplisit menyatakan hal tersebut didukung.

Perbandingan clean flash dan dirty flash

Kapan clean flash diperlukan?

Clean flash dapat diperlukan bila dokumentasi ROM untuk perangkat Anda memintanya, misalnya saat berpindah ROM atau ketika ada perubahan besar yang tidak mendukung dirty flash. Perubahan firmware atau recovery, bootloop, dan ketidakstabilan sistem tidak otomatis berarti data harus di-wipe atau diformat. Diagnosis masalah terlebih dahulu dan gunakan instruksi ROM sebagai dasar keputusan.

Kapan dirty flash mungkin aman?

Dirty flash mungkin aman bila:

  • ROM masih sama.
  • Versi Android tidak berpindah besar.
  • Firmware dasar tidak berubah.
  • Maintainer menyatakan dirty flash didukung.
  • Tidak ada perubahan struktur partisi.
  • Tidak ada perubahan mekanisme enkripsi.
  • Tidak ada masalah sistem sebelum update.

Meski demikian, backup tetap wajib. Dirty flash yang gagal tetap dapat membuat perangkat tidak dapat boot.

Contoh dari dokumentasi LineageOS

LineageOS menjelaskan bahwa aplikasi updater tidak mendukung upgrade dari satu versi LineageOS ke versi lain dan akan memblokir instalasi update untuk versi yang berbeda. Upgrade manual memerlukan langkah yang mirip dengan instalasi LineageOS pertama kali. [236]

Pada beberapa halaman upgrade, LineageOS menyatakan bahwa bila perangkat menjalankan versi LineageOS lebih lama dari 21.0, partisi data perlu di-wipe. Dokumentasi tersebut juga menegaskan bahwa langkah tersebut akan menghapus data pribadi dan aplikasi yang dipasang pengguna, sehingga backup harus dilakukan terlebih dahulu. [236][237]

Halaman instalasi LineageOS untuk beberapa perangkat juga menjelaskan bahwa Format data / factory reset akan menghapus enkripsi, menghapus file di penyimpanan internal, serta memformat partisi cache bila ada. [234][235]

Artinya, clean flash bukan sekadar “hapus aplikasi”. Format data dapat menghapus enkripsi, file internal, dan data aplikasi.

Jenis wipe yang perlu dipahami

Istilah dan opsi dapat berbeda antar recovery. Jangan menjalankan wipe hanya karena namanya mirip.

Mengapa dirty flash bisa gagal?

Dirty flash dapat gagal karena:

  • Perubahan besar pada framework Android.
  • Perubahan struktur partisi.
  • Perubahan mekanisme enkripsi.
  • Firmware dasar berubah.
  • Recovery tidak kompatibel.
  • Sisa data dari ROM lama menyebabkan konflik.
  • Aplikasi sistem atau modul lama tidak kompatibel.
  • OTA atau updater menolak versi yang berbeda.

LineageOS menjelaskan bahwa updater tidak mendukung upgrade lintas versi LineageOS dan akan memblokir instalasi untuk versi berbeda. [236] Ini menunjukkan bahwa mekanisme pembaruan ROM memiliki aturan kompatibilitas tersendiri.

Alur dirty flash yang aman

Backup tetap wajib

Dirty flash tidak menghapus data secara teori, tetapi tetap dapat gagal. Kegagalan boot, kerusakan partisi, atau kesalahan instalasi dapat membuat data tidak dapat diakses.

Sebelum clean flash maupun dirty flash, pastikan:

  • Foto dan video tersalin ke luar perangkat.
  • Dokumen penting tersalin.
  • Kode 2FA dan kode pemulihan tersimpan.
  • Backup aplikasi pesan selesai.
  • Backup Google atau backup cloud selesai.
  • File ROM, recovery, dan firmware tersimpan di luar perangkat.

Miskonsepsi umum

“Dirty flash selalu aman.”

Tidak. Dirty flash hanya aman bila ROM secara eksplisit mendukungnya dan kondisi perangkat sesuai.

“Clean flash selalu menghapus semua data.”

Keduanya bukan istilah yang dapat dipertukarkan. Dampaknya bergantung pada perangkat dan recovery; format data dapat menghapus enkripsi serta file penyimpanan internal. Ikuti istilah dan langkah tepat dalam panduan perangkat, setelah backup diverifikasi.

“Update kecil pasti bisa dirty flash.”

Tidak selalu. Perubahan kecil pada tampilan tidak berarti struktur sistem atau firmware tidak berubah.

“Ganti ROM bisa dirty flash.”

Umumnya tidak disarankan. Ikuti panduan ROM tujuan dan pastikan operasi wipe yang diwajibkan sebelum berpindah; jangan menyimpulkan bahwa format data diperlukan tanpa instruksi spesifik.

“Kalau dirty flash gagal, langsung format data.”

Jangan langsung. Lakukan diagnosis terlebih dahulu dan pastikan tidak ada langkah instalasi yang terlewat.

Checklist sebelum clean flash

  • Dokumentasi ROM sudah dibaca.
  • Firmware dasar sesuai.
  • Recovery kompatibel.
  • Backup lengkap dan terverifikasi.
  • Kode 2FA dan kode pemulihan tersimpan.
  • File ROM dan add-on sesuai codename.
  • Jenis wipe yang diperlukan sudah dipahami.
  • Langkah setelah instalasi sudah dipahami.
  • Perangkat tidak akan reboot sebelum instruksi selesai.

Checklist sebelum dirty flash

  • ROM masih sama.
  • Versi Android tidak berpindah besar.
  • Firmware dasar tidak berubah.
  • Maintainer menyatakan dirty flash didukung.
  • Tidak ada perubahan struktur partisi.
  • Backup lengkap dan terverifikasi.
  • Recovery kompatibel.
  • File ROM sesuai codename.
  • Langkah setelah instalasi sudah dipahami.
